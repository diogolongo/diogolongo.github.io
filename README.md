# My Personal Website

This is the source code for my personal website, built with [Hugo](https://gohugo.io/).

## Running Locally

To run the website locally, you need to have Hugo installed. You can find the installation instructions [here](https://gohugo.io/getting-started/installing/).

Once you have Hugo installed, you can run the following command to start the local server:

```bash
hugo server
```

This will start a local server at `http://localhost:1313/`. The website will automatically reload when you make changes to the source code.

To build the website, you can run the following command:

```bash
hugo
```

This will create a `public` directory with the generated website.
